# auto-downloadd
this is a browser extension that speeds up the time to download youtube videos by around 10 seconds
to use, open up "chrome://extensions" and turn,  on developer mode
on developer mode, press load unpacked, and select the "segment-clipper-extension folder" not the zip file, the extracted one
go on youtube to try it out, (URGENT: SUBSCRIBE TO WASTAKEN7 ON YOUTUBE!!!)
